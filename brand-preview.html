On one line the 32 character tagline was wider than the name, so it decided the lockup width and pushed it to 294px. On two lines the name decides it, which is how a lockup should behave. 1180px is the tightest case, not the narrowest: the nav is still on screen and at its smallest. Below 1080px the nav is hidden and the pressure comes off.

Mark alone, and the size test

The artwork is illustrated, so its fluting, chains and filigree stop resolving below about 40px. That is inherent to the drawing, not to the export.

The icons are transparent, with no tile behind them. Worth knowing what that trades: the mark is silver and copper, so it loses definition against a very dark or very light browser chrome, and a transparent touch icon renders on black on some older iOS versions. The manifest no longer declares the touch icon maskable, which requires an opaque image.

Portable lockups · for anything outside the site

821×288, transparent, 4× so it stays sharp when placed. Use these for email signatures, decks and social profiles, where the HTML component is not available. Inside the site, always use the component — its text is real and scales.

Where the real ceiling is. The type in these is vector, rasterised at size, so it is genuinely sharp at any dimension. The mark is not: the artwork supplied crops to 423×344, and that is the most detail that exists in it. The 1920 wide lockups upscale it 1.20×, which is mild enough not to read as soft. Past roughly 2300px wide it will start to.

None of these are referenced by any page, so they add nothing to what the site loads. If you need the mark larger than 423px with real detail, it has to be redrawn as vector or regenerated at a higher resolution at source.
